MySQL Joins Analysis Project 

A data analysis project demonstrating advanced SQL querying techniques by importing Excel datasets into a MySQL database to solve complex business questions.

📌 Project OverviewThis project showcases the practical application of SQL joins to merge and analyze relational data. The dataset originated from an Excel spreadsheet, which was structured, cleaned, and migrated into MySQL. A series of analytical business questions were then answered using optimized SQL queries.

🛠️ Tech Stack & ToolsDatabase Engine: MySQLData Source: Microsoft Excel (.xlsx / .csv)SQL Concepts: Inner Join, Left Join, Right Join, Data Aggregation (GROUP BY), Filtering (WHERE, HAVING).

❓ Business Questions Answered
The SQL scripts in this repository solve specific data challenges, including:
Identifying matching records across multiple tables using INNER JOIN.
Finding orphaned data and unfulfilled relations using LEFT JOIN / RIGHT JOIN.
Aggregating multi-table metrics to generate comprehensive business reports
